    ⬇️ Descargar app
    Cómo instalarla
    1. Toca Descargar app. Si el teléfono avisa que el archivo puede ser dañino, elige Descargar de todas formas.
    2. Abre el archivo descargado (en la notificación o en la carpeta Descargas).
    3. Si Android lo pide, permite Instalar apps desconocidas para tu navegador y vuelve atrás.
    4. Toca Instalar. Después la app se actualiza sola.
